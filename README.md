# Cyber

A collection of offensive security write-ups produced through hands-on practice, covering both web application vulnerabilities and low-level binary exploitation. Each project documents the methodology, root cause, and proof of concept for every challenge solved.

## Projects

### [HackAndJuice](./HackAndJuice)
Write-ups for **OWASP Juice Shop**, an intentionally vulnerable e-commerce web application used as an industry-standard benchmark for web security training. Covers the OWASP Top 10 categories in practice: injection, broken authentication, XSS, XXE, sensitive data exposure, and more.

### [ECorp](./ECorp)
Write-ups for a series of **binary exploitation (pwn) challenges** set in a fictional corporate CTF scenario. Covers stack overflows, heap corruption, format string bugs, and related memory-safety exploitation techniques against C binaries.
